## Primeros pasos

### Requisitos previos

Este proyecto ha sido creado y configurado para funcionar con el gestor de paquetes [pnpm](https://pnpm.io/installation), por lo que se recomienda instalar esta herramienta.

Este proyecto también está configurado utilizando [volta](https://volta.sh). Puedes instalar esta herramienta para asegurarte de que estás utilizando las versiones correctas de node y npm.

De todos modos, este proyecto debería funcionar con las siguientes versiones:

- node >= 18.17.0
- npm >= 9.6.7

Si tienes node y npm funcionando correctamente en tu máquina, puedes ejecutar el siguiente comando para instalar `pnpm` globalmente:

```shell
npm install -g pnpm
```

### Herramientas y bibliotecas utilizadas

- [Astro](https://astro.build/) framework web para sitios impulsados por contenido
- [React](https://reactjs.org/) para componentes dinámicos
- [MDX](https://mdxjs.com/) te permite usar JSX en tu contenido markdown
- [TypeScript](http://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com/) como guía de diseño
- [Prettier](https://prettier.io/) para formateo de código

### Instalación

Para instalar las dependencias requeridas debes ejecutar el siguiente comando:

```shell
pnpm i --frozen-lockfile
```

### Ejecutar

Para ejecutar la aplicación en modo de desarrollo (en tu máquina local habilitando la recarga en caliente) puedes usar:

```shell
npm run dev
```

## Contribución

Las contribuciones son lo que hacen de la comunidad de código abierto un lugar tan increíble para aprender, inspirarse y crear. Cualquier contribución que hagas es **muy apreciada**.

Si tienes una sugerencia que mejoraría esto, por favor haz un fork del repositorio y crea un pull request. También puedes simplemente abrir un issue con la etiqueta "enhancement".
¡No olvides darle una estrella al proyecto! ¡Gracias de nuevo!

1. Haz un fork del Proyecto
2. Crea tu rama de funcionalidad (`git checkout -b feature/AmazingFeature`)
3. Realiza los commits de tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Haz push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request
